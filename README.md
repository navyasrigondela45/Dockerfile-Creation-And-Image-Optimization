# Dockerfile Creation And Image Optimization

This repository contains Dockerfile creation and image optimization for multiple technology stacks.

## Tech Stacks

- Nginx
- HTTPD
- Node.js
- Python
- Java (Tomcat Deployment)
- MySQL

---

## Repository Structure

Each stack contains:
- Dockerfile.v1
- Dockerfile.v2
- Application source files
- Optimized Docker image setup
- Output screenshots

---

## Project Highlights

### Dockerfile.v1
- Standard Docker image deployment

### Dockerfile.v2
- Optimized lightweight deployment
- Reduced image size

---

## Outputs Included

- Docker image build output
- Optimized image comparison
- Running container output
- Browser/application output

---

## Optimization Concepts

- Alpine images
- Layer optimization
- Lightweight container deployment
- Port mapping
- Container troubleshooting
